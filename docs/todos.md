- **P2** — после MVP, в текущий объём не входит.
- `[ФАКТ]` — проверено по источнику; `[РЕШЕНИЕ]` — проектное решение; `[ПРЕДПОЛОЖЕНИЕ]` — требует проверки; `[ВОПРОС]` — нужно решение владельца.
