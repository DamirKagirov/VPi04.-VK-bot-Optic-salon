# Требования и границы MVP

**Продукт:** ВКонтакте-бот сети салонов оптики «Ясные очи».
**Цель:** помочь посетителю познакомиться с услугами, увидеть ориентировочные цены, открыть
карточку услуги и связаться с менеджером.
**Этап:** проектирование. Реализация не начата.

## 1. Проблема и аудитория

`[ПРЕДПОЛОЖЕНИЕ]` Посетители сообщества задают типовые вопросы об услугах и ценах, а менеджер
тратит время на повторяющиеся ответы. Бот снимает часть этой нагрузки и даёт структурированную
информацию в мобильном интерфейсе ВКонтакте.

Аудитория:

- клиенты, которые выбирают салон и услугу;
- существующие клиенты, которым нужна цена или описание;
- менеджеры, которым важно не терять диалог с человеком.

## 2. Границы MVP

### Входит

| № | Возможность |
|---|---|
| 1 | Главное меню |
| 2 | Полный список услуг (10 карточек) |
| 3 | Прайс-лист |
| 4 | Карточка услуги: описание, состав, цена, оговорки |
| 5 | Переход к менеджеру через диалог сообщества |
| 6 | Возврат к списку услуг и в главное меню |
| 7 | Ответ на неизвестный ввод |
| 8 | Корректная обработка устаревших кнопок |
| 9 | «Тихий режим», чтобы не мешать переписке с человеком |
| 10 | Понятные ошибки конфигурации при запуске |

### Не входит

- онлайн-оплата;
- полноценная запись на приём и выбор слота;
- CRM, интеграции с телефонией;
- программа лояльности и бонусы;
- рассылки и сегментация;
- AI-консультант и генерация ответов;
- авторизация и личный кабинет;
- хранение медицинских данных и результатов обследований;
- аналитика персональных данных;
- несколько сообществ или мультибот;
- веб-интерфейс администратора;
- база данных.

## 3. Роли

| Роль | Возможности |
|---|---|
| Посетитель | открывает меню, листает услуги, смотрит цены и карточки, переходит к менеджеру |
| Менеджер | отвечает в диалоге сообщества; бот не вмешивается в переписку в тихом режиме |
| Владелец каталога | меняет JSON-файл услуг и цен без изменения кода |
| Администратор | запускает процесс, следит за логами, обновляет токен |

## 4. Пользовательские сценарии

1. **Первый запуск.** Пользователь нажимает «Начать» или пишет боту, получает приветствие
   и главное меню.
2. **Повторное обращение.** Пользователь снова открывает диалог и видит меню; прошлый экран
   не восстанавливается.
3. **Просмотр услуг.** Пользователь открывает список, выбирает услугу, читает карточку.
4. **Сравнение цен.** Пользователь открывает прайс-лист и видит те же цены, что в карточках.
5. **Возврат.** Пользователь возвращается к списку и в главное меню.
6. **Связь с менеджером.** Пользователь открывает экран связи, переходит в диалог сообщества,
   подтверждает, что написал менеджеру, и бот перестаёт отвечать на обычные сообщения.
7. **Неизвестный ввод.** Пользователь пишет произвольный текст и получает подсказку.
8. **Устаревшая кнопка.** Пользователь нажимает кнопку из старого сообщения; бот открывает
   актуальный раздел или сообщает, что раздел недоступен.

## 5. Функциональные требования

Приоритеты: **P0** — без этого MVP не готов; **P1** — важно, можно уточнить при реализации.

| ID | Требование | Приоритет | Проверка |
|---|---|---|---|
| FR-01 | Бот отвечает на первое обращение приветствием и показывает главное меню | P0 | AC-01, AC-16 |
| FR-02 | Главное меню содержит «Услуги», «Прайс-лист», «Связаться с менеджером» | P0 | AC-01 |
| FR-03 | Список услуг показывает все 10 услуг кнопками | P0 | AC-02 |
| FR-04 | Каждая кнопка услуги открывает карточку с названием, полным описанием, составом, ценой и оговорками | P0 | AC-03 |
| FR-05 | Цена в карточке и в прайс-листе формируется из одного поля каталога и совпадает символ в символ | P0 | AC-04, AC-15 |
| FR-06 | Прайс-лист содержит все 10 услуг и дисклеймер о проектных ценах | P0 | AC-04 |
| FR-07 | Из карточки можно вернуться к списку и в главное меню | P0 | AC-05 |
| FR-08 | Из списка можно вернуться в главное меню | P0 | AC-05 |
| FR-09 | Экран менеджера содержит ссылку на диалог сообщества и объяснение, что отвечает человек | P0 | AC-06 |
| FR-10 | После подтверждения «Я написал менеджеру» бот переходит в тихий режим | P0 | AC-06, AC-13 |
| FR-11 | В тихом режиме бот не отвечает на обычный текст и на неизвестные payload | P0 | AC-12 |
| FR-12 | Выход из тихого режима — только явная кнопка «В главное меню» или истечение TTL | P0 | AC-13 |
| FR-13 | Неизвестный текст или неизвестная команда получают понятный ответ и меню | P0 | AC-07 |
| FR-14 | Устаревшая кнопка с валидным действием работает; с неизвестным ID — сообщает об этом и предлагает актуальный раздел | P0 | AC-08 |
| FR-15 | При отсутствии обязательной переменной окружения процесс завершается с понятной ошибкой без вывода секрета | P0 | AC-09 |
| FR-16 | Ошибка API ВКонтакте не завершает процесс; она логируется, бот продолжает работу | P0 | AC-10 |
| FR-17 | После перезапуска бот сохраняет тихий режим и не ломает навигацию | P0 | AC-11 |
| FR-18 | Каталог и тексты меняются без изменения кода обработчиков | P1 | AC-15 |
| FR-19 | Бот не хранит текст сообщений и медицинские данные | P0 | AC-17 |
| FR-20 | Бот работает в одном процессе через LongPoll, без веб-сервера | P0 | AC-11 |

## 6. Бизнес-правила контента

| ID | Правило |
|---|---|
| BR-01 | Цены — проектные оценки, а не действующий прайс «Ясных очей». Это указано в прайс-листе и карточках |
| BR-02 | Названия, описания и цены берутся из одного JSON-файла; дублирование в коде запрещено |
| BR-03 | Нельзя обещать лечение, диагностику заболеваний или медицинский результат |
| BR-04 | Нельзя приписывать «Ясным очам» лицензии, оборудование и квалификацию без подтверждения |
| BR-05 | ID услуг стабильны; при переименовании меняется название, но не ID |
| BR-06 | Услуги, требующие подтверждения, помечены флагом и не публикуются до ответа владельца |
| BR-07 | Связь с менеджером — обычная переписка ВКонтакте, а не автоматическая передача диалога |
| BR-08 | Бот не консультирует по медицинским вопросам и не заменяет специалиста |

## 7. Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-01 | Время ответа бота (без сети ВКонтакте) — до 1 секунды на типовое действие |
| NFR-02 | Запуск процесса — до 5 секунд, включая чтение каталога |
| NFR-03 | Один процесс, один экземпляр бота; горизонтальное масштабирование не требуется |
| NFR-04 | Работа 24/7 под супервизором; падение процесса не должно требовать ручного вмешательства |
| NFR-05 | Логи с ротацией; токен и тексты сообщений не логируются |
| NFR-06 | Все секреты — только в `.env`; `.env` исключён из Git |
| NFR-07 | Каталог редактируется без программиста; ошибка в JSON не должна приводить к неверным ценам |
| NFR-08 | Тексты и кнопки — на русском языке, без сложных терминов |
| NFR-09 | Подписи кнопок ≤ 40 символов, payload ≤ 255 символов |
| NFR-10 | Бот корректно работает с мобильного клиента ВКонтакте |
| NFR-11 | Нет обязательных изображений и вложений: интерфейс остаётся текстовым |
| NFR-12 | Зависимости зафиксированы точными версиями |

## 8. Ограничения

- Только ВКонтакте, только сообщество, только LongPoll.
- Python 3.12/3.13, `vkbottle==4.11.0`, `python-dotenv==1.2.4`.
- Нет базы данных, Docker, очередей, веб-сервера.
- Нет доступа к фактическим данным «Ясных очей».
- Живая документация VK была недоступна; часть фактов подтверждена архивом.
- Медицинские услуги нельзя публиковать до подтверждения владельцем.

## 9. Допущения

1. `[ПРЕДПОЛОЖЕНИЕ]` В сообществе можно включить LongPoll и выпустить токен с нужными правами.
2. `[ПРЕДПОЛОЖЕНИЕ]` Нажатие текстовой кнопки приходит как `message_new` с payload.
3. `[ПРЕДПОЛОЖЕНИЕ]` Менеджер отвечает в том же диалоге сообщества.
4. `[ПРЕДПОЛОЖЕНИЕ]` Каталог из 10 услуг покрывает основные запросы.
5. `[ПРЕДПОЛОЖЕНИЕ]` Нагрузка не требует нескольких процессов.
6. `[ПРЕДПОЛОЖЕНИЕ]` Владелец сможет подтвердить услуги и цены до запуска.

## 10. Глоссарий

| Термин | Значение |
|---|---|
| Карточка | Экран с полным описанием одной услуги |
| Прайс-лист | Одно сообщение со всеми названиями и ценами |
| Payload | JSON в кнопке, по которому бот понимает действие |
| Тихий режим | Состояние, в котором бот не отвечает на обычные сообщения |
| TTL | Время жизни тихого режима, по умолчанию 12 часов |
| Каталог | JSON-файл с услугами, ценами и текстами |
| Устаревшая кнопка | Кнопка из старого сообщения или старой версии каталога |
