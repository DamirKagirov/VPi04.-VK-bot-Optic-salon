# ВКонтакте-бот для сети салонов оптики «Ясные очи»

Проектная документация MVP-бота сообщества: каталог услуг, прайс-лист, карточки услуг и связь
с менеджером.

**Статус:** MVP реализован и покрыт тестами; токен проверен, LongPoll подключается;
выполнен короткий smoke-запуск. Полная проверка сценариев в клиенте ВКонтакте ещё не
проводилась · **Дата:** 11.11.2026 · **Этап:** подготовка к эксплуатации.

> Это не действующий прайс-лист «Ясных очей». Все цены в документации — проектные оценки,
> основанные на открытых прайсах сопоставимых салонов Москвы и Московской области. Они требуют
> согласования с владельцем сети.

## Кратко о решении

| Параметр | Решение |
|---|---|
| Платформа | ВКонтакте, бот сообщества |
| Получение событий | LongPoll API (не Callback API) |
| Язык | Python 3.12 или 3.13 |
| Библиотека | `vkbottle==4.11.0` |
| Конфигурация | `.env` + `python-dotenv==1.2.4` |
| Каталог | один JSON-файл `catalog/services.json` |
| Услуги | 10 услуг с постоянными ID |
| Навигация | кнопки с `payload`, без хранения текущего экрана |
| Связь с менеджером | диалог сообщества `243094422`, в нём же работает бот |
| Состояние | только «тихий режим» менеджера в `runtime/state.json` |
| База данных | не нужна |
| Веб-сервер, Docker, очереди | не нужны |
| Окружение | `.venv313`, Python 3.13.7 |
| Тесты | `pytest==9.2.0`, 83 теста |

## Что входит в MVP

- главное меню;
- полный список услуг;
- прайс-лист из того же источника данных, что и карточки;
- карточка каждой услуги: описание, состав, цена, оговорки;
- переход к менеджеру через диалог сообщества;
- возврат к списку услуг и в главное меню;
- ответ на неизвестный ввод;
- корректная работа с устаревшими кнопками;
- «тихий режим», чтобы бот не мешал переписке с человеком.

## Что не входит в MVP

Онлайн-оплата, полноценная запись на приём, CRM, программа лояльности, рассылки,
AI-консультант, авторизация пользователей, хранение медицинских данных, аналитика
персональных данных.

## Ограничения

- Живые страницы `dev.vk.com` на момент проверки были недоступны как источник (SPA-оболочка
  или сообщение о недоступности). Использованы архивные копии; это зафиксировано в
  [`sources.md`](sources.md).
- Медицинские услуги, оборудование, лицензии и квалификация специалистов «Ясных очей»
  не подтверждены. До подтверждения соответствующие карточки нельзя публиковать как факт.
- Ссылка на диалог сообщества и фактический процесс работы менеджера неизвестны.
