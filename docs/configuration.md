## 3. Переменные окружения

`[РЕШЕНИЕ]` Настройки читаются из `.env` через `python-dotenv`. Переменные процесса имеют
приоритет над файлом.

| Переменная | Обязательна | По умолчанию | Назначение | Валидация |
|---|---|---|---|---|
| `VK_BOT_TOKEN` | да | — | токен бота сообщества | непустая строка, не содержит пробелов; значение не логируется |
| `MANAGER_CONTACT_URL` | да | — | ссылка на диалог сообщества для кнопки «Написать менеджеру» | начинается с `https://vk.com/`, `https://vk.me/` или `https://vk.ru/` |
| `MANAGER_MODE_TTL_HOURS` | нет | `12` | срок тихого режима в часах | целое, `1…168` |
| `LOG_LEVEL` | нет | `INFO` | уровень логирования | `DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `STATE_PATH` | нет | `runtime/state.json` | путь к файлу тихого режима | непустая строка, каталог создаётся |
| `CATALOG_PATH` | нет | `catalog/services.json` | путь к каталогу услуг | непустая строка, файл должен существовать |

`[РЕШЕНИЕ]` Переменные с путями относительны корня проекта. Абсолютные пути допустимы,
но не обязательны.

`[ФАКТ]` 11.11.2026 выбрана ссылка `https://vk.ru/club243094422`; она записана в `.env`.
Это сообщество бота (проверено `groups.getById`), в нём же отвечает живой менеджер (Q-04,
Q-05, Q-17). Бот не строит ссылку сам, а берёт её из `.env`.

`[ВОПРОС]` Нужен ли отдельный `VK_GROUP_ID`? VKBottle определяет `group_id` через
`groups.getById`, поэтому в MVP переменная не нужна. Если возникнет несколько сообществ
или неоднозначность токена, переменная добавляется.

## 5. Поведение при ошибках конфигурации

`[РЕШЕНИЕ]` Проверка выполняется до создания `Bot` и до обращения к ВКонтакте.

| Ситуация | Сообщение | Код выхода |
|---|---|---|
| Нет `VK_BOT_TOKEN` | `Не задан VK_BOT_TOKEN. Добавьте его в .env.` | 2 |
| Пустой `VK_BOT_TOKEN` | то же | 2 |
| Нет `MANAGER_CONTACT_URL` | `Не задан MANAGER_CONTACT_URL. Добавьте его в .env.` | 2 |
| URL не начинается с разрешённой схемы | `MANAGER_CONTACT_URL должен начинаться с https://vk.com/, https://vk.me/ или https://vk.ru/.` | 2 |
| `MANAGER_MODE_TTL_HOURS` не число или вне диапазона | `MANAGER_MODE_TTL_HOURS должен быть целым от 1 до 168.` | 2 |
| `LOG_LEVEL` неизвестен | `Неизвестный LOG_LEVEL. Допустимо: DEBUG, INFO, WARNING, ERROR.` | 2 |
| Каталог не найден | `Каталог не найден: <путь>.` | 3 |
| Каталог невалиден | `Ошибка каталога: <поле/ID>: <причина>.` | 3 |
| Нет прав на запись `STATE_PATH` | предупреждение в лог; работа без сохранения тихого режима | 0 |

`[РЕШЕНИЕ]` Сообщения об ошибках не содержат значений переменных. Для токена выводится только
имя переменной.

`[ПРЕДПОЛОЖЕНИЕ]` Если каталог валиден, но содержит услуги с `requires_owner_confirmation=true`,
бот всё равно запускается: флаг — организационное, а не техническое ограничение. До
подтверждения владельцем такие карточки не должны публиковаться в сообществе.

## 7. Секреты и гигиена

`[РЕШЕНИЕ]` Правила:

1. Токен хранится только в `.env` на машине запуска.
2. `.env` не коммитится, не отправляется в чат, не вставляется в документацию.
3. В коде нет значения токена по умолчанию.
4. Токен не выводится в `--help`, `--version`, сообщениях об ошибках и трейсбеках.
5. Логи не содержат заголовков HTTP-запросов и параметров LongPoll.
6. При подозрении на утечку токен перевыпускается в сообществе.
7. Доступ к серверу и `.env` есть только у ответственного администратора.

`[ФАКТ]` `API.__repr__` и `__repr__` генератора токена в `v4.11.0` не содержат значения
токена (проверено по исходному коду). Это не отменяет требования фильтрации логов.

`[РЕШЕНИЕ]` При логировании используется `RedactingFormatter`: он заменяет токен и строки,
похожие на токен ВКонтакте, на `***` в готовой строке лога, включая traceback. Тест на
отсутствие токена в логах входит в приёмку (`AC-09`).

## 9. Эксплуатационные параметры

| Параметр | Значение | Обоснование |
|---|---|---|
| Один процесс | да | LongPoll не предназначен для нескольких конкурирующих потребителей |
| Автозапуск | systemd / Windows-служба / аналог | процесс должен подниматься после падения |
| Рабочая директория | корень проекта | относительные пути каталога, состояния и `ts` |
| Ротация логов | по размеру или дню | не переполнять диск |
| Резервная копия | `catalog/services.json`, `.env` — отдельно | контент и секрет |
| Мониторинг | наличие процесса + ERROR в логах | минимально достаточно для MVP |
| Обновление цен | правка JSON + валидация + перезапуск | каталог читается при старте |
| Ответственный за каталог | админ бота, файл на сервере бота | Q-10; период «30 дней» требует уточнения |
| Периодичность сверки | 30 дней (предварительно) | Q-10; уточнить, относится ли срок к сверке каталога или к журналу |

`[ПРЕДПОЛОЖЕНИЕ]` Часовой пояс сервера — Москва. TTL считается в UTC и хранится с
смещением, чтобы не зависеть от настроек машины.
